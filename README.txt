뭐입었지 v1

1. GitHub Pages / Netlify / Vercel 같은 HTTPS 정적 호스팅에 폴더 전체를 올립니다.
2. iPhone: Safari에서 주소 열기 → 공유 → 홈 화면에 추가
3. Android: Chrome에서 주소 열기 → 메뉴 → 앱 설치/홈 화면에 추가

v1 기능
- 월 / 주 / 일 보기
- 날짜별 여러 착장 사진 기록
- 착장별 메모
- 하단 '기록하기'는 오늘 날짜로 바로 기록
- 달력에서 날짜를 선택한 뒤 '+ 착장 추가'하면 해당 날짜에 기록
- 사진 내보내기(공유 시트 또는 다운로드)
- IndexedDB 기기 저장
- PWA manifest + service worker

주의
- 브라우저 데이터 삭제, 기기 교체 시 기록이 사라질 수 있습니다.
- v2에서 클라우드 백업/로그인으로 확장할 수 있도록 데이터 구조를 분리해 두었습니다.
